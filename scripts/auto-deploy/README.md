# 智能自动化部署系统 v2.0

## 功能特性

✅ **全自动部署流程**
- 自动提交部署到 CloudBase
- 实时轮询部署状态
- 智能失败检测

✅ **智能错误分析**
- 自动获取部署日志
- 识别 8+ 种常见错误类型
- 精准定位错误位置

✅ **自动修复问题**
- 自动修复重复变量定义
- 自动修复导入路径错误
- 自动重新打包

✅ **循环重试机制**
- 失败自动修复后重试
- 最多重试 10 次
- 直到部署成功或无法修复

## 使用方法

### 方式一：一键部署（推荐）

```bash
cd scripts/auto-deploy
bash run.sh
```

这个命令会：
1. 预修复常见问题
2. 自动部署并监控
3. 失败时自动分析修复重试
4. 成功后健康检查

### 方式二：单独使用

**仅预修复：**
```bash
node fix-common-issues.js
```

**仅自动部署（含监控和重试）：**
```bash
node auto-deploy-v2.js
```

## 部署流程

```
┌─────────────────┐
│   1. 预修复      │  ← 修复重复变量、导入路径
└────────┬────────┘
         ▼
┌─────────────────┐
│   2. 提交部署    │  ← 上传代码到 CloudBase
└────────┬────────┘
         ▼
┌─────────────────┐
│   3. 轮询状态    │  ← 每15秒检查一次
└────────┬────────┘
         ▼
    ┌────────┐
    │ 成功？  │
    └────┬───┘
   是 /    \ 否
     /      \
    ▼        ▼
┌───────┐  ┌───────────┐
│健康检查│  │4. 获取日志 │
└───┬───┘  └─────┬─────┘
   │              ▼
   │         ┌───────────┐
   │         │5. 分析错误 │
   │         └─────┬─────┘
   │              ▼
   │         ┌───────────┐
   │         │6. 自动修复 │
   │         └─────┬─────┘
   │              ▼
   │         ┌───────────┐
   │         │7. 重新打包 │
   │         └─────┬─────┘
   │              │
   └──────────────┘
         ▼
   ┌──────────┐
   │ 重试部署  │  ← 回到步骤2
   └──────────┘
```

## 自动修复的错误类型

| 错误类型 | 说明 | 自动修复 |
|---------|------|---------|
| DUPLICATE_VARIABLE | 变量重复定义 | ✅ 自动删除重复 |
| IMPORT_PATH_ERROR | 导入路径错误 | ✅ 自动修正层级 |
| SYNTAX_ERROR | 语法错误 | ❌ 需手动修复 |
| TYPE_ERROR | TypeScript 类型错误 | ❌ 需手动修复 |
| MISSING_MODULE | 缺少依赖模块 | ❌ 需手动安装 |
| BUILD_ERROR | 构建失败 | ✅ 尝试修复 |
| DOCKER_ERROR | Docker 构建错误 | ❌ 需检查 Dockerfile |
| MEMORY_ERROR | 内存不足 | ❌ 需调整配置 |

## 配置

如需修改配置，编辑 `auto-deploy-v2.js` 中的 `CONFIG` 对象：

```javascript
const CONFIG = {
  envId: 'your-env-id',           // CloudBase 环境ID
  serviceName: 'your-service',    // 服务名称
  maxRetries: 10,                 // 最大重试次数
  pollInterval: 15000,            // 状态轮询间隔(毫秒)
  maxPollTime: 600000             // 最大等待时间(毫秒)
};
```

## 注意事项

1. 确保已登录 CloudBase: `tcb login`
2. 确保有部署权限
3. 自动修改的代码会自动提交到 Git
4. 如遇到无法自动修复的错误，需要手动修改代码
