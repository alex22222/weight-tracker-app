# L1 全量数据库备份方案

## 1. 概述

本方案为体重追踪应用提供 **L1 全量数据库备份**，通过定时任务每2天自动执行一次，用于灾难恢复。

## 2. 架构

```
┌──────────────────────────────────────────┐
│              数据源层                       │
│  ┌─────────────┐  ┌─────────────────┐   │
│  │   SQLite    │  │  CloudBase NoSQL │   │
│  │ (开发环境)   │  │   (生产环境)     │   │
│  └──────┬──────┘  └────────┬────────┘   │
└─────────┼──────────────────┼────────────┘
          │                  │
          ▼                  ▼
┌──────────────────────────────────────────┐
│              备份执行层                     │
│         全量数据库备份（每2天）              │
│  ┌─────────────────────────────────────┐ │
│  │  SQLite: 文件复制 + SQL 转储         │ │
│  │  CloudBase: 各集合 JSON 导出         │ │
│  └─────────────────────────────────────┘ │
└──────────────────────────────────────────┘
          │
          ▼
┌──────────────────────────────────────────┐
│              存储层                         │
│  ┌─────────────┐  ┌─────────────────┐   │
│  │ 本地备份目录  │  │  GitHub Artifacts│   │
│  │ ./backups/   │  │   (保留30天)     │   │
│  └─────────────┘  └─────────────────┘   │
└──────────────────────────────────────────┘
```

## 3. 备份策略

- **频率**: 每2天执行一次（北京时间 03:00）
- **保留**: 最近 30 天的备份 + 每月 1 号的月度归档
- **存储**:
  - 开发环境: `backups/` 本地目录
  - 生产环境: CloudBase 云存储 + GitHub Artifacts
- **格式**:
  - SQLite: `.db` 文件副本 + `.sql` 转储
  - CloudBase: 各集合 `.json` 导出

## 4. 数据模型映射

| Prisma 模型 | CloudBase 集合 | 备份内容 |
|-------------|---------------|---------|
| User | users | 用户基础信息 |
| WeightEntry | weight_entries | 体重记录 |
| UserSettings | user_settings | 用户设置 |
| Message | messages | 消息 |
| Friend | friends | 好友关系 |
| FitnessChannel | fitness_channels | 健身频道 |
| ChannelMember | channel_members | 频道成员 |
| CheckIn | check_ins | 打卡记录 |
| (其他) | channel_comments, leave_requests, goals, tasks, ... | 扩展业务数据 |

## 5. 恢复策略

| 场景 | 恢复方式 | RTO | RPO |
|------|---------|-----|-----|
| 整库损坏 | L1 全量备份恢复 | < 1 小时 | 48 小时 |
| 单表/集合损坏 | 从对应 JSON/SQL 文件选择性恢复 | < 30 分钟 | 48 小时 |

## 6. 文件清单

| 文件 | 说明 |
|------|------|
| `src/lib/backup-service.ts` | 备份核心逻辑 |
| `scripts/backup-database.js` | 定时备份脚本 |
| `scripts/restore-database.js` | 恢复脚本 |
| `.github/workflows/backup-database.yml` | GitHub Actions 自动备份 |
